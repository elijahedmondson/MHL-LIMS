# Outside IHC sources

The question (November 2026): can the MHL LIMS IHC database show information from the Human Protein Atlas, Antibodypedia, CiteAb, NordiQC, ImmunoQuery and the Antibody Registry (RRIDs) beside MHL's own assay records?

Yes, but how depends on what each source allows. Two of them publish open data that the LIMS may import and keep (the Human Protein Atlas and the Antibody Registry). Three are free to read but do not allow their content to be copied into another database (Antibodypedia, CiteAb, NordiQC). One is a paid subscription (ImmunoQuery). So the LIMS imports the first two, links to the other four, and lets staff save the page they found with a short note in their own words. Pilot version 11 does all of this (Molecular > Outside sources, and a new Outside sources section on every assay page).

MHL's own catalog stays the record of how each stain is run and whether it works at MHL. Outside data is shown beside the protocol and never overwrites it.

## How relevant each one is to MHL

Most of MHL's IHC is on mouse tissue, and four of the six sources are about human tissue: the HPA stains human tissue, Antibodypedia lists antibodies against human targets, and NordiQC and ImmunoQuery are for human diagnostic pathology. For mouse work, the most useful outside information is the RRID (exactly which product was used, for methods sections and NIH rigor requirements) and citation evidence (CiteAb). For human tissue, PDX and organoids, the HPA, NordiQC and ImmunoQuery are directly useful: expected staining pattern, positive control tissues and clones that perform well. The pilot shows a caution on HPA data for protocols not listed for human tissue: it shows where the human protein is found, which helps choose control tissue, but is not evidence that a mouse antibody works.

## What the pilot does (version 11)

**Identifiers on each assay.** Every single-antibody protocol can carry the target's gene symbol (human, such as MKI67; the mouse symbol also works), UniProt accessions and the antibody's RRID. N/A marks a tag or reagent with no gene, or a product with no RRID. Panels and double stains are left to their single-stain protocols. Changes are in the assay's history. The catalog search and the main Look up search find assays by gene symbol or RRID, and the Excel download of the catalog has Target gene and RRID columns.

**Links.** Each assay page lists the six sources with the best page for that assay: the HPA gene page and antibody page when the gene is known (a search otherwise), the RRID record (or a registry search by catalog number), and for the link-only sources the landing page with the text to search for and a Copy button. Antibodypedia, CiteAb and NordiQC have no reliable search address, and the pilot does not guess one.

**Saved pages and notes.** Staff can save the exact page they found (a CiteAb product page, a NordiQC recommended protocol, an Antibodypedia validation) with a note of up to 400 characters. Only http and https addresses on the chosen source's own site are accepted ("Other" takes a datasheet or paper anywhere). The note is meant to be a summary in the user's own words, which keeps within the terms of the link-only sources.

**HPA import.** On Molecular > Outside sources, staff choose the HPA's `proteinatlas.tsv.zip` and then `normal_tissue.tsv.zip`, as downloaded. The browser reads them in pieces (plain, .zip or .gz; files of hundreds of megabytes are fine) and keeps only genes the catalog may need, matched on gene symbols, HPA synonyms and common IHC names (about 1,000 names and symbols to look for). The assay page then shows IHC and IF reliability (with what each level means), protein evidence, RNA tissue specificity, the HPA antibodies with their RRIDs, and normal tissue staining (High, Medium and Low by tissue and cell type, a guide to control tissue), with "Data from the Human Protein Atlas version X, used under CC BY 4.0".

**Antibody Registry import.** Staff choose the registry's CSV download. Only rows whose catalog number matches one of the catalog's single catalog numbers are kept: the same number, a size or format of it ("14-0195" and "14-0195-82"), or a letter suffix ("9027" and "9027S"). RRIDs are then suggested on catalog number and vendor (vendor names are matched across owners and brands, such as PharMingen and BD Biosciences, eBioscience and Thermo Fisher). A bare number such as 9027 only matches when the vendor matches too. The catalog's HPA antibodies (such as HPA002198) get their RRIDs from the HPA data.

**Suggestions and review.** Gene symbols are suggested from a list of common IHC names (Ki67 is MKI67, F4/80 is ADGRE1, B220 is PTPRC, and so on), from names written like symbols, and, once the HPA is imported, from HPA symbols and synonyms. A tag or label (GFP, BrdU, ApopTag) is suggested as N/A only when it is the whole name, so "I-Ad, biotin" is not mistaken for a label. About 570 of the 702 single-antibody protocols get a suggestion before any import. Nothing is filled in automatically: staff accept suggestions on the assay page, or tick them in bulk on the review list ("Tick the strong ones shown" picks common IHC names, HPA symbols that are the whole name, HPA synonyms that belong to one gene only, tags, and RRIDs with the same catalog number and vendor; a synonym shared by several genes, or one word of a longer name, is left for a person to choose). Accepting fills only empty fields, and each acceptance is in the assay's history.

**Data and size.** The data file moves to version 9; saved data upgrades on start-up with empty identifiers. Imported data is kept small: at most 1,500 genes in the gene summary, 600 genes with 16 tissue rows each, and 3,000 registry rows, and the pilot refuses an import that would take the imported data over 2 million characters, so it fits beside everything else in the standalone file's browser storage (about 5 million). If the browser ever cannot save, the standalone now says so instead of losing changes silently.

**Samples.** `pilot/samples/outside-sources` has files in the layout of the real downloads with made-up values (written by `tools/outside-samples/make_outside_samples.py`). Real gene symbols, Ensembl IDs and UniProt accessions are used so the links work; reliability, tissue levels and RRIDs (AB_999xxxx) are invented.

**Not yet checked.** The column names in the real HPA and registry downloads were taken from their documentation and published descriptions; the build environment could not download the files. The readers find columns by name, accept common variants, and list any they could not find. Importing the real files is the first test (open question 61).

## Production design

**Where it is stored.** Three columns on the assay (`TargetGene`, `UniProt`, `Rrid`) and an `AssayReference` table (assay, source, address, note, saved by, saved at), both with temporal history like the rest of the schema. The imported data goes in its own reference tables (`ref.HpaGene`, `ref.HpaNormalTissue`, `ref.AntibodyRegistryEntry`), each row stamped with the source version and import date, plus an import log. Nothing outside writes into the assay's protocol fields.

**How it is refreshed.** A scheduled job on the LIMS server, not each user's browser: it downloads the HPA files after each HPA release (usually about once a year) and keeps the genes the catalog needs, and it asks the Antibody Registry API for the RRIDs of new or changed catalog numbers instead of handling the 3-million-row file. This needs outbound HTTPS from the server to proteinatlas.org and antibodyregistry.org (and scicrunch.org if its API is used, with an API key), approved through NIH and NCI network security (open question 63).

**Attribution and terms.** HPA data carries its version and the CC BY 4.0 notice wherever it appears, on screens and in exports. The LIMS keeps no content from Antibodypedia, CiteAb, NordiQC or ImmunoQuery beyond links and staff-written summaries, unless NCI obtains a licence or written permission (open question 62); if it does, integration would go through that source's API under the agreement.

**Worth doing next.** RRIDs are most useful when investigators get them: an IHC request's deliverables could list each stain as "Vendor Cat# …, RRID:AB_…" ready for a methods section, which journals and NIH increasingly ask for. That needs the IHC team to fill in RRIDs for the antibodies in use, which the suggestions make quick.
